Coffre du lab

Mode d'emploi détaillé

Ce navigateur n'a pas encore de coffre. Choisissez :

Je n'ai pas encore de coffre

À faire une seule fois. Vous allez choisir une phrase de passe, puis enregistrer un fichier de clé sur une clé USB.

J'ai déjà un fichier de clé

Vous avez créé votre coffre sur un autre navigateur ou un autre appareil : branchez la clé USB qui porte votre fichier .coffre-cle.

Créer mon coffre — étape 1 sur 3 : la phrase de passe

Cette phrase protège votre fichier de clé. Personne ne peut la retrouver pour vous, pas même l'administrateur du lab. Une phrase de cinq mots ou plus, que vous seul connaissez, est le meilleur choix (par exemple quatre ou cinq mots sans rapport entre eux).

Création de la clé… (quelques secondes)

Créer mon coffre — étape 2 sur 3 : enregistrer le fichier de clé sur une clé USB

  1. Branchez une clé USB sur cet ordinateur.
  2. Cliquez sur le bouton ci-dessous et choisissez la clé USB comme emplacement.
    Si votre navigateur enregistre le fichier directement dans « Téléchargements » sans rien demander : ouvrez ce dossier, déplacez (et non copiez) le fichier vers la clé USB, puis videz la corbeille.
  3. Recommencez avec une seconde clé USB, que vous rangerez dans un autre endroit.

N'envoyez jamais ce fichier par Internet : ni par email, ni par messagerie, ni dans un service en ligne (Drive, Dropbox, OneDrive, iCloud…). Avec ce fichier et votre phrase de passe, n'importe qui lit tous vos mots de passe. La seule voie prévue est la clé USB.

Créer mon coffre — étape 3 sur 3 : vérifier votre copie

Pour être sûr que la copie est bonne, ouvrez le fichier depuis la clé USB (pas depuis « Téléchargements ») :

Utiliser mon fichier de clé

  1. Branchez la clé USB qui porte votre fichier .coffre-cle.
  2. Choisissez ce fichier ci-dessous, directement sur la clé USB.
  3. Saisissez votre phrase de passe.

Ouverture… (quelques secondes)

Le navigateur garde ensuite une copie chiffrée du fichier : vous pouvez retirer la clé USB. Vous n'aurez plus besoin que de votre phrase de passe ici.

Utiliser un autre fichier de clé

Retire le coffre actuel de ce navigateur pour en charger un autre. Vos fichiers sur clé USB ne sont pas touchés.

Coffre ouvert

Verrouillage automatique

Refaire une copie du fichier de clé

Pour remplacer une clé USB perdue ou abîmée. Même consignes : sur une clé USB, jamais par Internet.

Changer de phrase de passe

Cela produit un nouveau fichier de clé. Remplacez-le sur toutes vos clés USB et dans vos autres navigateurs, puis effacez les anciens fichiers : un ancien fichier s'ouvre toujours avec l'ancienne phrase.

Retirer le coffre de ce navigateur

Utile avant de rendre ou de prêter cet ordinateur. Vos fichiers sur clé USB ne sont pas touchés : vous pourrez le recharger.
